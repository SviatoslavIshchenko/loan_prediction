# Прогнозування схвалення кредиту (Loan Prediction)

## Опис проєкту

**Loan Prediction** — навчальний проєкт для прогнозування ймовірності схвалення кредитної заявки на основі характеристик позичальника.

Проєкт охоплює основні етапи роботи з машинним навчанням: дослідницький аналіз даних (EDA), підготовку даних, побудову та оцінювання моделей, а також створення вебзастосунку Django для використання навченої моделі.

Для прогнозування у вебзастосунку використовується модель **Logistic Regression**.

## Використані технології

- **Python** — основна мова програмування.
- **Pandas, NumPy** — обробка та аналіз даних.
- **Matplotlib, Seaborn** — візуалізація даних.
- **Scikit-learn** — побудова й оцінювання моделей машинного навчання.
- **Jupyter Notebook** — виконання EDA та експериментів із моделями.
- **Django** — створення вебзастосунку.
- **SQLite** — збереження історії прогнозів.
- **HTML, CSS** — створення вебінтерфейсу.
- **OpenPyXL** — експорт результатів у Excel.

## Етапи розробки

### 1. Дослідницький аналіз даних (EDA)

На першому етапі проводиться дослідження набору даних щодо кредитних заявок.

Основна мета EDA — ознайомитися зі структурою даних, перевірити їхню якість і дослідити характеристики, які можуть бути пов'язані зі схваленням кредиту.

Матеріали аналізу представлені у Jupyter Notebook:

**[01_EDA.ipynb](notebooks/01_EDA.ipynb)**

Файл розміщений у папці `notebooks/`.

### 2. Побудова моделей машинного навчання

На наступному етапі здійснюється підготовка даних для моделювання, навчання моделей та оцінювання результатів прогнозування.

Код експериментів із моделями зберігається в окремому Jupyter Notebook:

**[02_Machine_Learning.ipynb](notebooks/02_Machine_Learning.ipynb)**

Для роботи вебзастосунку обрано модель **Logistic Regression**.

### 3. Розробка вебзастосунку Django

Навчена модель інтегрована у вебзастосунок, який дозволяє вводити характеристики позичальника та отримувати прогноз і ймовірність схвалення кредиту.

## Дані проєкту

У папці `data/` зберігаються два Excel-файли, які використовувалися під час аналізу та моделювання.

- **[loan_data.csv](data/loan_data.csv)** — вихідний набір даних щодо кредитних заявок.
- **[loan_data_eda.csv](data/loan_data_eda.csv)** — набір даних, отриманий після проведення EDA-аналізу.

Ці файли дозволяють ознайомитися з даними й повторити відповідні етапи дослідження.

## Основні можливості вебзастосунку

### Прогнозування кредиту

Користувач вводить характеристики позичальника: стать, сімейний стан, кількість утриманців, освіту, самозайнятість, доходи, суму та термін кредитування, кредитну історію і тип місцевості.

Модель Logistic Regression обчислює ймовірність схвалення кредитної заявки.

### Історія прогнозів

Результати прогнозування зберігаються в базі даних SQLite.

Користувач може переглядати історію прогнозів, кількість прогнозованих схвалень і відмов та основні характеристики кредитних заявок.

### Деталі прогнозу

Для кожного прогнозу доступна окрема сторінка з повною інформацією про позичальника, фінансовими показниками та результатом прогнозування.

### Важливість факторів

Окрема сторінка містить середні абсолютні значення коефіцієнтів логістичної регресії для факторів кредитування.

Ці показники не є відсотками впливу факторів на рішення щодо кредиту.

### Експорт результатів

Історію прогнозів можна експортувати у формати **CSV** та **Excel (.xlsx)**.

## Запуск вебзастосунку

### 1. Клонування репозиторію

```bash
git clone https://github.com/SviatoslavIshchenko/loan_prediction.git
cd loan_prediction
```

### 2. Створення віртуального середовища

Для Windows із встановленим Python 3.13:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Встановлення залежностей

```powershell
python -m pip install -r requirements.txt
```

### 4. Підготовка бази даних

```powershell
python manage.py migrate
```

### 5. Запуск сервера

```powershell
python manage.py runserver
```

Вебзастосунок буде доступний за адресою:

http://127.0.0.1:8000/

## Призначення проєкту

Проєкт створено з навчальною метою для демонстрації практичних навичок аналізу даних, машинного навчання та веброзробки з використанням Python і Django.

Результати моделі є прогнозами та не становлять фактичного рішення фінансової установи щодо надання кредиту.
